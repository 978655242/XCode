# Aiscoo Web account entry

The product composition never creates the upstream browser OAuth owner and never reads, clears or migrates its saved credentials. Unsupported remote and share callback routes report Aiscoo sign-in unavailable before callback parsing or relay admission. Missing or invalid account origins fail closed with a fixed configuration message.

Only the existing exact loopback browser New API authority may serve local login. Its PKCE, SID, generation, refresh and attachment ownership remain unchanged. This module does not extend callbacks, CORS, pairing, relay, Host state or transport recovery.

Public shares use the existing loader and readonly renderer with anonymous fetch (`credentials: omit`, redirects rejected). Protected or hidden/not-found shares report that Aiscoo sign-in is unsupported, without official provider controls or old account hints. The loader owns view state only; it never accepts a session or credential.
