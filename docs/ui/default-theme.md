# 默认主题

## 当前策略

- 应用首次启动且本地没有 `zcode-theme` 持久化值时，默认主题为 `dark`。
- 一旦用户主动切换主题，后续仍然优先读取本地保存值，不会被默认值覆盖。
- 桌面 HTML 启动壳在 React 接管前读取同一个 `zcode-theme` 值：`light` / `zai-light` 使用浅色，`dark` / `zai-dark` 使用深色，`system` 跟随系统；缺失或无法读取时默认深色。启动壳背景和 Logo 使用相同明暗主题，并与 React 启动页的 Zai 背景一致。
- 用户启用减少动态效果时使用对应主题的静态 Logo；更新状态窗口继续跳过启动壳。启动壳只投影现有主题偏好，不写入存储，也不提前改变原生窗口主题。

## 验收场景

- 浅色系统搭配已保存的深色应用主题，以及深色系统搭配已保存的浅色应用主题，从 HTML 启动壳到 React 启动页始终保持应用主题。
- 无保存值默认深色；`system` 跟随系统外观；历史 `light` / `dark` 值仍可用。静态和动态 Logo 都与启动壳背景保持一致。
- 启动壳移除后，现有应用主题同步、原生窗口材质、更新状态窗口和主界面启动流程保持原有时序。

## 实现位置

- Zustand store 默认值：`packages/ui/src/store/index.ts`
- 旧 `useTheme()` hook 兜底值：`packages/ui/src/useTheme.ts`
