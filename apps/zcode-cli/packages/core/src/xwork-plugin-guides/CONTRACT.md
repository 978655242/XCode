# Workspace auxiliary text stream

`streamWorkspaceModelText(runtime, input, {abortSignal?, onDelta})` creates one workspace model binding, emits real text deltas, requires a supported finish, and calls existing usage recording for completion, cancellation or failure. It reuses provider refresh, model invocation context, and admission. No session turn, messages, model selection, tools or nonstream fallback are created. A partial/error/length/tool completion rejects and cannot become a saved guide. The caller owns operation correlation and cancellation. Local usage persistence remains subject to the existing persisted-session foreign key; calling its best-effort helper does not prove a usage row was stored.

The request output budget is capped by the bound model's public `optionSpecs.maxOutputTokens.max`; an omitted budget uses that maximum. An explicit `selection.options.reasoningLevel` reaches the Model executor unchanged and is validated by the existing Model implementation. Only an absent reasoning choice uses the first public level from `auxiliaryModelOptions`. The result selection includes the actual execution reasoning. All options and selections are request-local copies and do not mutate ordinary session selection, reasoning settings or drafts.
