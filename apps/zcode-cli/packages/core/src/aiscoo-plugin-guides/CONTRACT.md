# Workspace auxiliary text stream

`streamWorkspaceModelText(runtime, input, {abortSignal?, onDelta})` creates one workspace model binding, emits real text deltas, requires a supported final finish, and records each actual model invocation's usage for completion, cancellation or failure. It reuses provider refresh, model invocation context, and admission. No ordinary session turn, message, model selection, tool execution or nonstream fallback is created. The caller owns one operation correlation and cancellation deadline across all continuations. Local usage persistence remains subject to the existing persisted-session foreign key; calling its best-effort helper does not prove a usage row was stored.

The request output budget is capped by the bound model's public `optionSpecs.maxOutputTokens.max`; an omitted budget uses that maximum. An explicit `selection.options.reasoningLevel` reaches the Model executor unchanged and is validated by the existing Model implementation. Only an absent reasoning choice uses the first public level from `auxiliaryModelOptions`. The result selection includes the actual execution reasoning. All options and selections are request-local copies and do not mutate ordinary session selection, reasoning settings or drafts.

Output-limit responses reuse the regular harness classifier and continuation prompt: append the actual assistant text/reasoning signatures and continue at most three times, without changing the pinned model/options or per-request token budget. One initial call plus three continuations is the maximum. The caller receives concatenated real text deltas and the final successful result; a fourth truncated response fails with the harness output-limit error. Error, refusal, tools or cancellation still reject without committing a guide. Temporary continuation messages never enter normal session history or guide question history. Returned usage sums only metrics known in every request, while per-request usage is recorded independently.
